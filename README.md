# 🌌 Cidadela - Rick and Morty API Integration

## 📖 Sobre o Projeto

O **Cidadela** é uma aplicação desenvolvida para consumir e processar dados da famosa [The Rick and Morty API](https://rickandmortyapi.com/). O projeto tem como objetivo principal demonstrar habilidades em integração de APIs externas, manipulação de dados e deploy de aplicações na nuvem.

🔗 **Acesse a aplicação em produção:** [Cidadela no Render](https://cidadela-39su.onrender.com/)

## ✨ Funcionalidades

* **Integração de Dados:** Consumo de endpoints da API externa do Rick and Morty (Personagens, Episódios, Localizações).
* **Persistência de Dados:** Salvamento das requisições e dados processados em um banco de dados relacional.
* **Deploy em Nuvem:** Aplicação totalmente conteinerizada/configurada e disponível online 24/7.
* **[Adicione outras funcionalidades específicas, ex: Filtro de personagens por status, paginação, etc]**

## 🛠️ Tecnologias Utilizadas

* **Backend:** Java com Spring Boot
* **Banco de Dados:** PostgreSQL
* **Hospedagem/Deploy:** Render
* **Integração:** RestTemplate / WebClient *(ajuste conforme o que você usou)*
